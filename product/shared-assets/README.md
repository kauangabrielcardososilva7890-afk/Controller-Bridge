# Shared brand assets

The approved Controller Bridge mark is used by the Android launcher and Windows host. `ControllerBridge.ico` is the Windows application icon. The Android launcher image is stored in the app's `drawable-nodpi` resources.

# Recursos visuais compartilhados

A marca aprovada do Controller Bridge é usada no ícone do Android e do host Windows. `ControllerBridge.ico` é o ícone do aplicativo para Windows. A imagem do Android fica nos recursos `drawable-nodpi` do app.
